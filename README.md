# KFC Clone - Food Ordering Mobile Application

## Overview

KFC Clone is a mobile food ordering application developed using Flutter. The app allows users to browse menu items, explore categories, view product details, add items to their cart, and place orders through a modern and intuitive interface inspired by leading food delivery platforms.

## Features

* Browse Food Categories
* View Menu Items and Details
* Add and Remove Items from Cart
* Order Placement
* Responsive User Interface
* Real-Time Data Management
* Smooth Navigation Experience

## Technologies Used

* Flutter
* Dart
* Supabase
* REST APIs
* Git & GitHub

## Installation

1. Clone the repository.
2. Run `flutter pub get`.
3. Run `flutter run`.
